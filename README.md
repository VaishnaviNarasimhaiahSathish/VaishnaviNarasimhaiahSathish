## 🚀 What I'm Currently Working On

### 🔹 ROS2 LiDAR Perception & Tracking

Built a **ROS2 point-cloud perception and tracking pipeline** using voxel filtering, RANSAC ground removal, Euclidean clustering, and Kalman filtering.

- Processed LiDAR data at **~10 Hz**
- Achieved **~85% track continuity**
- Analyzed clustering errors, missed objects, and track losses during occlusions
- Visualized detections and tracks using RViz

**Tech:** Python, C++, ROS2, Open3D, RViz

---

### 🔹 RGB-Depth Sensor Fusion for Object Detection

Built a feature-level **RGB-depth fusion pipeline** for indoor object detection using the NYU Depth V2 dataset.

- Compared RGB-only and RGB-depth fusion models
- Depth integration improved detection precision by **~8%**
- Worked with cross-modal preprocessing and spatial alignment

**Tech:** Python, PyTorch, OpenCV, Faster R-CNN

---

### 🔹 Multi-Camera Person Detection & Tracking

Developed a **3-camera person detection and tracking pipeline** combining YOLOv5 and DeepSORT with cross-camera identity association.

- Achieved **~72% MOTA**
- Maintained **25–30 FPS** real-time processing
- Handled identity association across camera views and occlusions

**Tech:** Python, PyTorch, YOLOv5, DeepSORT, OpenCV

---

### 🔹 Stereo Depth Estimation

Implemented a stereo-vision pipeline for **depth reconstruction from calibrated camera pairs**.

- Performed camera calibration, rectification, and disparity estimation using StereoSGBM
- Validated depth against ground-truth distances from **0.5–3 m**
- Achieved **~4.5 cm MAE** and **~6% mean relative error**

**Tech:** Python, OpenCV, StereoSGBM, NumPy

---

### 🔹 Fridge-to-Recipe Assistant

Developed a vision-language system for **open-vocabulary ingredient extraction and recipe recommendation**.

- Compared Qwen and Gemma vision-language models for ingredient extraction
- Evaluated predictions using precision, recall, F1, and ingredient-set similarity
- Connected extracted ingredients to BM25-based recipe retrieval and ranking

**Tech:** Python, Qwen, Gemma, Vision-Language Models, BM25, Streamlit

---

### 🔹 Document Search & Retrieval

Built a **Retrieval-Augmented Generation (RAG) pipeline** for semantic document search.

- Generated transformer-based document embeddings
- Implemented vector similarity search using FAISS
- Evaluated retrieval quality using precision and recall

**Tech:** Python, Hugging Face Transformers, Sentence Transformers, FAISS, RAG
